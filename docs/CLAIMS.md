## What each benchmark arm measures

- Arm A (owner + notary addressing, notary on): the human canary is never delivered as addressed, so its count measures Switch routing. No LLM decision is involved.
- Arms B and D (open addressing): the injection is delivered as addressed, so their human canary counts measure the agent.
- The content canary sits inside an offer note and reaches the agent in every arm, so that row measures the agent everywhere.
