# Live checks

Switch behaviour the build depends on that the source code says should work but that must be confirmed on a running install. Each check runs before the first piece of work that depends on it. A failed check switches to its fallback; nothing else changes.

L2 and L8 are superseded, L5 and L10 are folded into L13a, and L4 is stretch only.
